# FusionStatusBar 0.3.173

本版汇总 0.3.152-0.3.173 的控制中心布局、材质与绘制修复，并新增系统菜单外观和电源菜单扩展。

## 新增与改进

- 横屏沿用自定义布局，支持跨面板分组、组合卡片和独立组件位置，旋转后保留竖屏坐标。
- 分组成员可独立调整图标大小，范围 25%-200%。
- 新增全局容器材质与柔光玻璃；磁贴、网络卡片、音乐、融合中心、分组及滑条统一外观。
- 全局描边提供独立开关和 1-4 dp 宽度，沿实际形状绘制。
- 电源菜单、音量菜单、通知中心和悬浮通知可分别启用外观接管；音量条支持标准和短款。
- 三条电源菜单保留中央关机/重启滑条，增加线刷模式、卡刷模式、飞行模式和静音模式操作。

## 修复

- 修复圆形磁贴外圈偏移、底板裁切、多层底色和透明装饰层硬件轮廓造成的遮罩。
- 统一音乐与融合中心的底色和形状，处理原生材质更新覆盖自定义外观的问题。
- 描边使用实际空心路径，修复部分绘制路径将边缘显示为实心区域的问题。
- 保留图标、文字、封面和滑条进度颜色，避免背景材质误染前景。
- 修复首次绑定、延迟更新、导入布局和 SystemUI 重启后的材质恢复。
- APK 内重启系统界面先等待已提交配置写入；保存失败时取消重启，未推送草稿继续保留。

## 安装与兼容性

- 包名继续为 `io.github.yudigaga.fusionstatusbar`，使用原签名，可覆盖安装 0.3.150、0.3.151 正式版。
- 最低 Android 13（API 33），需要支持 LibXposed API 102 的框架。作用域为 `com.android.systemui`，存在 `miui.systemui.plugin` 时也勾选。
- 旧包 `com.xtjm.fusionstatusbar` 需先导出配置，再在新版导入；LSPosed 中只启用一个模块。
- 电源菜单等系统功能取决于 ROM 提供的接口；本次未进行实体手机安装、SystemUI 注入或目标 ROM 验收。
