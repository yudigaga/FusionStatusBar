# 状态栏 Hook 安装职责拆分（0.3.135）

`SystemUiHooks.install()` 原先同时解析状态栏目标类、逐组注册 Hook、维护全局句柄统计和执行所有业务回调。本版本增加 `StatusBarHookInstaller`，将状态栏目标解析与五组 Hook 声明提取为一个按次创建的对象。

installer 通过目标 ClassLoader 解析电池视图、图标容器、电池容器、电话状态栏/基类和锁屏状态栏；通过窄接口提交方法和对应回调。实际 LibXposed 注册仍由 `SystemUiHooks` 的适配器完成，因此真实句柄、去重、失败重试、回调实现和运行时能力判断保持原有宿主路径。

测试覆盖目标缺失时兄弟组继续安装、单方法缺失不阻断同组其他方法、注册失败只在后续安装重试，以及不同 ClassLoader 定义同名类时方法不串用。未进行实体设备验证。
