# FusionStatusBar 0.5.19

本地 Release，版本 `0.5.19`，构建号 `233`。使用既有正式证书，可覆盖升级。

## 返回停顿修正

- 第一段沿用系统拉起反馈；停稳 500 ms 时发出第二段震动，提示可以松手执行。动作执行时不再补震。
- 连续快速侧滑保留系统返回。已配置且可用的返回停顿，停稳 100 ms 后进入等待；未就绪便松手会取消这次手势，避免误退上一页。等待时明显继续移动会重新计时并恢复滑动判定。
- 进入距离继续使用当前桌面的原生门槛。进入后增加按屏幕密度换算的退出容差；停顿前允许 12 dp 的边界回撤，就绪后允许 24 dp。停顿抖动半径为系统 touchSlop 与 16 dp 的较大值。
- 提示和松手共用就绪状态。轻微抬手漂移不再被原生 finish 标志推翻；明确回撤、取消、多指及动作不可用仍取消。已发出的提示不被迟到的旧历史坐标追溯撤销。
- 定时使用与触摸事件一致的 uptime 截止时间，不再把事件投递延迟叠加到等待时长。
- 保留渐变彩虹、其他外观预设以及同色系随系统日夜模式切换。

配置入口：桌面 → 桌面手势 → 返回停顿。安装后重启系统桌面和系统界面，或重启设备，确认对应 LSPosed 作用域已启用。
