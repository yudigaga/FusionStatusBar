# 音乐与融合中心底色 v0.3.169

用户已实机确认 0.3.168 解决磁贴遮罩。本版继续处理音乐和融合中心底色偏浅的问题：两个组件应使用未开启磁贴的底色。

音乐的 MediaPlayerPanel 与融合中心的 DeviceCenterEntryFrameLayout 均在根 View 持有使用 externalEntryBgColor 的 GradientDrawable。现有背景注册已经按未开启状态选择颜色，但组件的 updateBlendBlur() 仍应用原生视图混色，部分 ROM 材质分支还启用 mix effect。磁贴的软件底板已接管这些效果，而这两个组件未进入同一策略，最终显示可能再次变浅。

现在只对这两个有标准可控底板的根 View，在自定义材质生效期间接管原生混色、视图模糊和独立背景模糊。底板使用现有统一的未开启状态色和卡片透明度策略。内部图标、封面、按钮和设备列表不进入此新增接管分支。原有背景、关闭自定义、原生编辑模式恢复最后的原生材质请求。配置刷新、重新创建底板和后续原生效果更新都重新判断接管条件。

新增 ControlCenterComponentMaterialTest 的三个用例在旧代码均失败，修复后通过。覆盖两个真实根类型、全部自定义材质与未开启磁贴的像素对比、内部图标保色、晚到原生更新、材质刷新、背景重建以及禁用/原生编辑时恢复。测试中的原生接口由可观测替身提供，不能代替目标 ROM 的最终颜色验收。

完整测试、lint、签名和版本检查记录在 artifacts/releases/v0.3.169/release.json。未安装或操作实体手机。
