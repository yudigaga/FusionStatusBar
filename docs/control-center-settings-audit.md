# 控制中心设置整理（0.3.118）

## 入口核对

| 原入口或设置 | 本次处理 | 原因 |
| --- | --- | --- |
| 控制中心设置、显示效果 | 合并为“布局与外观” | 原先打开同一设置对话框 |
| 组合卡片、添加磁贴、组件、网格资源 | 合并到“添加项目” | 单层列表统一选择磁贴、组件或组合卡片 |
| 磁贴风格 | 删除界面选择器 | 已核对配置没有参与当前画布和实际布局绘制；保留旧字段兼容存量配置 |
| 磁贴顺序原始字符串 | 删除输入框 | 画布直接表达项目位置及排列，避免两套编辑入口 |
| 磁贴管理 | 移入“更多”，更名“系统磁贴管理” | 保留有效的全局磁贴资源开关，并说明作用范围 |
| 实际截图中的旧版编辑入口 | 改为只读参考 | 项目形状和尺寸统一在画布编辑，拉取与导入入口保留 |
| 多处启用开关 | 页面仅保留一个“自定义控制中心”开关 | 开关编辑草稿，推送后应用 |

## 页面视觉与行为

- 圆角卡片分组：启用与外观、布局画布、真实布局参考。
- 标准／紧凑布局提供明确选中样式，摘要反映当前画布列数和项目数量。
- 画布工具栏缩减为“添加项目、撤销、更多”；清空和恢复原生布局收入更多菜单。
- 真实截图默认收起，拉取成功后点标题展开；拉取和导入按钮集中在参考卡片。
- 推送使用主色按钮，并显示当前草稿状态；无修改时禁用。
- 统一按钮触控高度、间距和浅色／深色配色，保持已有形状与尺寸渲染逻辑。
- 布局与外观分为“当前画布”和“全局外观”，明确列数、内容缩放、圆角、间距的作用范围。

- 修复导入画布缺失撤销记录的问题，撤销恢复导入前的标准和紧凑草稿。
