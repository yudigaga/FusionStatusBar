# FusionStatusBar 0.3.192

版本号 `0.3.192`，构建号 `206`。本次汇总上一个远端正式版 `0.3.187` 到当前版本的全部变化，包含 `0.3.188-0.3.192`。

## 0.3.188：桌面功能与手势

- 原概述页改为桌面页；模块状态、设备信息和关于信息移入设置页，移除权限板块。
- 支持隐藏指定应用的桌面和底栏图标；关闭开关或取消选择后可恢复图标。
- 支持单指/双指上下滑、底栏左右滑、摇动、空白区域双击、捏合和扩展，共十种桌面手势。
- 动作支持通知中心、控制中心、锁定设备、熄屏、截图、最近任务、电源菜单、侧边栏、应用、快捷方式、活动、功能切换、清理内存、单手模式和清理通知。
- 功能切换支持 Wi-Fi、蓝牙、位置、NFC、声音模式、自动亮度、旋转、手电筒、移动数据、热点、勿扰模式和系统深色模式。
- 属性点击“完成”保存，取消丢弃草稿；应用、活动和快捷方式需选择目标才能保存。过期系统动作会被丢弃。

## 0.3.189：桌面重启与应用目录

- 设置页新增“重启系统桌面”，重启 `com.miui.home` 并返回桌面；原有“重启系统界面”继续单独提供。
- 确认重启后先等待设置保存；保存失败、页面销毁或重复请求不会执行重启。
- 应用选择纳入冻结/停用、桌面入口停用和暂停的应用；活动选择纳入已安装应用及停用活动。
- 选择器展示状态标记，保留冻结应用作为配置目标；实际启动遵循系统限制。

## 0.3.190：应用搜索与图标

- 隐藏应用、启动应用和活动所属应用列表支持名称/包名搜索，忽略大小写和首尾空格。
- 搜索支持一键清除和空结果状态；应用行展示彩色图标、名称、包名及冻结/停用/暂停状态。
- 图标按需加载并使用有界缓存，缺失图标回退至系统默认图标。
- 跨搜索条件保留隐藏应用勾选；点击“完成”保存，取消丢弃修改。筛选后保留原始目标 ID 和查询不到的隐藏应用配置。

## 0.3.191-0.3.192：Compose/Miuix 全页面迁移

- 桌面、状态栏、通知栏、控制中心和设置页统一使用 Compose/Miuix 0.8.8；五页导航、预览模式和启动加载界面同步迁移。
- 设置行、开关、滑块、输入框、分组标题及命令按钮使用 Miuix 控件。
- 手势属性、动作、应用、活动、快捷方式、公共选择、组合成员、恢复/备份确认、预设输入和诊断选项使用 `WindowBottomSheet`。
- 保留配置、Hook、动作 ID 和保存协议；状态栏/通知预览、控制中心画布及触摸编辑继续复用原有引擎。
- 保留控制中心草稿、撤销/重做、锁定、组合、样式、布局校验和明确推送行为。
- 选择列表保留图标、可用状态和原始条目 ID；时间格式和预设输入继续显示校验错误。
- 完善深色控件内容色、大字体导航标签、组合图标尺寸输入与滑杆同步，以及按钮选中状态。
- 应用、活动目录和图标在后台读取；Activity 销毁时取消任务并释放 Compose 页面及弹窗。导入导出继续使用系统文件选择器。
- 构建环境升级至 JDK 21、Gradle 8.13、AGP 8.13.2、Kotlin/Compose Compiler 2.3.20、编译 SDK 36；最低 API 33、目标 SDK 35。Miuix Apache-2.0 许可随源码及 APK 提供。

## 升级须知

- 包名和签名沿用原正式版，可覆盖安装 `0.3.187`。
- LSPosed 作用域为 `com.android.systemui`、`miui.systemui.plugin`、`com.miui.home` 和 `com.miui.securitycenter`。升级后启用新增桌面与安全中心作用域，并重启对应进程或设备。
- 侧边栏动作需先开启系统侧边栏；“重启系统桌面”需要设备已授予 FusionStatusBar root 权限。
