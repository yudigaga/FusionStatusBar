# 应用语言切换与界面资源化

日期：2026-11-09。本次源码版本为 **0.5.25 / 239**。最终APK、校验值及签名以[本版归档清单](../artifacts/releases/v0.5.25/release.json)为准。

在模块 **设置 → 界面 → 应用语言** 中选择语言。无需修改手机的系统语言，也不需要为设置界面的语言变化重启 SystemUI 或手机管家。

| 选项 | 语言 tag |
| --- | --- |
| 跟随系统 | 空应用语言列表，清除覆盖 |
| 简体中文 | `zh-Hans` |
| 繁體中文 | `zh-Hant` |
| English | `en` |
| 日本語 | `ja` |
| 한국어 | `ko` |
| Русский | `ru` |
| Español | `es` |

选项名称使用各语言自己的写法，便于在不熟悉的语言中找回设置。“跟随系统”使用当前界面的译文。

## 语言保存与设置保护

模块最低支持 Android 13，使用原生 `LocaleManager` 保存应用语言。系统管理语言选择及相应的 Activity 配置重建；重新打开设置仍读取该选择。“跟随系统”写入空 `LocaleList`，不另存一份可能与系统状态冲突的语言偏好。系统的应用语言列表声明七种语言，跟随系统是第八个选择模式。

切换前先完成正在进行的设置保存或明确发起的控制中心发布事务。保存失败时取消语言请求、恢复当前语言的选择显示，不因语言切换丢失修改或把失败当成成功。等待期间发生旋转或 Activity 重建，会保存待切换语言及明确的保存目标，新 Activity 重新提交该目标，等待成功后再切换。

未推送的控制中心草稿保持为草稿，不借语言切换自动发布。当前页面、滚动位置、编辑会话和杂项配置随重建恢复；标准／紧凑模式和正在发布的快照各自保持原有含义。

## 资源化范围与边界

当前每种语言有 **850 条 string**，覆盖简中默认资源及繁中、英文、日文、韩文、俄文、西班牙文六套译文。模块设置、导航、对话框、控制中心画布与编辑器、无障碍提示，以及手机管家26项杂项的分类、标题和说明均改为资源读取。含数量、尺寸和状态的动态文案使用完整格式模板，译文保留参数编号与类型。

共享视图和本次资源化的宿主文案通过 `ModuleStrings` 读取模块资源。传入宿主 Context 时先建立模块包的资源 Context，并采用宿主的配置，避免把模块资源 ID 当成宿主 ID 读取。应用语言设置只允许模块自身 Context 操作，不改变 SystemUI、桌面或手机管家进程的全局 Locale；原有宿主电池统计文案保持既有行为。无格式参数时按字面值读取，保留百分号、时间格式示例等内容。

以下内容保持原值：用户填写的名称与文本、应用和系统提供的标签、已保存的时钟格式、枚举／spec／JSON键、广播动作与协议字段、日志和错误码。中文农历、干支和中文时段输出继续沿用既有格式语义；帮助中的对应输出例子、品牌及署名也保留。

主要实现入口为 `AppLanguageSettings`、`ModuleStrings`、`MainActivity.requestAppLanguage/continuePendingAppLanguage/resumePendingAppLanguage` 和 `res/xml/locales_config.xml`。资源完整性按默认资源与各语言的键集合、XML属性、格式占位符和转义进行核对。
