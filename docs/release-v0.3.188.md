# FusionStatusBar v0.3.188

基于最新正式版 0.3.187 增加 MIUI/HyperOS 桌面设置，保留原有状态栏与控制中心修复。

## 更新内容

- 原概述页改为桌面页；模块状态、设备信息与关于信息移入设置页，移除权限板块。
- 桌面页支持选择应用并隐藏其桌面和底栏图标，关闭开关或取消选择可恢复图标。
- 支持单指/双指上下滑、底栏左右滑、摇动、空白区域双击、捏合与扩展共十种手势。
- 动作包含通知中心、控制中心、锁定设备、熄屏、截图、最近任务、电源菜单、侧边栏、应用、快捷方式、活动、功能切换、清理内存、单手模式及清理通知。
- 功能切换包含 Wi-Fi、蓝牙、位置、NFC、声音模式、自动亮度、旋转、手电筒、移动数据、热点、勿扰模式及系统深色模式。“夜间模式”切换界面深色模式。
- 桌面页面的分组、设置行、颜色与字体沿用现有页面规范；属性及选择弹窗共用状态栏设置的底部弹窗控制器。
- 属性编辑在“完成”时保存，退出编辑丢弃草稿；应用、活动和快捷方式必须选择目标才能保存。
- 系统动作由受限 Provider 队列传递给 SystemUI；过期命令丢弃，避免 SystemUI 后续启动时执行旧手势。快捷方式由桌面进程查询和启动。

## 作用域

沿用 `com.android.systemui` 与 `miui.systemui.plugin`，新增 `com.miui.home` 和 `com.miui.securitycenter`。首次安装后需要在 LSPosed 中启用新增作用域，并重启对应进程或设备。侧边栏动作使用系统已有侧边栏，需要先在系统设置中启用侧边栏。
