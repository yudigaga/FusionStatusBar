# FusionStatusBar 0.5.18

本地 Release APK，版本 `0.5.18`、构建号 `232`。使用原有正式证书签名，支持覆盖升级 `0.5.17`。

## 更新内容

- 返回停顿在确认 500 ms 后保留就绪资格，修正已复现的抬手坐标变化导致漏触发；静止时没有 MOVE 事件也可完成确认。
- 按触摸采样发生时间处理迟到历史和松手；回撤、取消、多指、新手势会撤销就绪和旧计时。距离规则优先使用当前宿主的原生判断。
- 拉起保留系统准备反馈，自定义触发完成原生取消后补齐结束反馈，再执行动作；复用宿主马达适配，缺失契约时按系统设置使用 CONFIRM。
- 重做紧凑叶片、悬浮胶囊、细弧和薄边微光；新增第六项“渐变彩虹”，多色主体和细边随侧滑进度变化。
- 所选背景和箭头作为基色保存，同色系自动派生日间、夜间显示色，并随当前系统模式更新；保留用户透明度，支持同一视图日→夜→日切换。
- 新增每次手势结束的结果和计时摘要，便于区分未就绪、原生拒绝和已请求自定义动作。

动画与配色参考及对应许可证见 [GitHub 源码调研](2026-10-26_side-back-animation-github-research.md)。日志证据、确定性复现与验证边界见 [稳定性和两段反馈报告](2026-10-26_back-gesture-stability-feedback-report.md)。

## 使用

安装后重启系统桌面和系统界面，或重启设备。确认 LSPosed 已启用 `com.miui.home` 与 `com.android.systemui` 作用域。

- 返回停顿动作：桌面 → 桌面手势 → 返回停顿。
- 彩虹与其他样式：桌面 → 侧滑返回外观 → 动画预设 → 渐变彩虹。
- 背景基色、箭头基色支持色板与 RGB/ARGB 输入，预览随系统当前模式显示。
