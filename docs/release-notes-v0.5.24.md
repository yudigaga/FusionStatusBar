# FusionStatusBar 0.5.24

版本 `0.5.24`，Android 构建号 `238`。本版先启用 Release R8 代码压缩、优化与混淆，再生成正式签名包。Xposed 入口采用精确保留规则；映射、最终配置及验包结果随验证附件发布。

## 功能更新

- “融合图标 → 显示 → 充电时显示充电图标”默认开启；关闭后，充电期间使用电量数字，圆环配色、位置和缩放保持原有配置。旧配置缺少该字段时默认开启。
- “杂项 → 截屏 → 截屏自动写入剪贴板”默认关闭。开启后系统侧保护唯一目标 Secure 设置键，关闭时写回 `0` 并解除保护；原系统权限和跨用户检查仍执行。
- “杂项 → 手机管家扩展”提供 26 项独立选项，默认全部关闭，另有参考亮屏时间的显示粒度设置。新增映射仅适配 `com.miui.securitycenter`、`13.8.0-261020.0.1`、versionCode `40001380`，未知版本保留对应原生行为。

手机管家选项主要改变本地入口、支持判断、名单或显示，不增加缺失硬件，也不保证实际游戏/视频、充电或检测效果。具体功能和限制见 [手机管家实施报告](2026-11-09_security-center-13.8-report.md)。充电显示与截图保护说明分别见 [充电图标开关](2026-11-09_fusion-charging-icon-switch.md)、[截图剪贴板](2026-11-09_screenshot-clipboard.md)。

## 安装与验证

沿用原正式证书，可覆盖更新 `0.5.21` 及后续本地正式签名版本。首次加载系统侧截图保护时，确认已勾选“系统（system / system_server）”并整机重启；以后开关修改按配置通知应用。手机管家扩展需勾选 `com.miui.securitycenter` 并重启相关进程或手机，修改后可能需要重建对应页面或工具箱。仅重启 SystemUI 不等于重启手机管家。

本版没有新增 LSPosed 作用域；升级时核对已有系统、SystemUI、插件、桌面与手机管家作用域。影院等入口仍依赖原生组件，缺少杜比支持时可能导致手机管家崩溃；本版尚未完成手机安装、真实 LSPosed 回调、ROM、硬件或服务效果验收。

R8 构建、两套完整单元测试、lint、工具测试及签名检查的最终计数，以 [本次构建记录](../artifacts/release-v0.5.24.json)和[验证摘要](../artifacts/validation-v0.5.24.md)为准。普通 JVM 单元测试执行在混淆前类上；优化 APK 另行检查入口与打包边界，不能代替设备验收。远端 CI 以发布提交对应的 GitHub Actions 为准。

本次重构建的 Debug、Release 各 `204` 个测试类、`1572` 项测试全部通过，失败、错误、跳过均为 `0`；两套完整 lint 均为 `0` 错误、`101` 条警告。Python 工具测试 `45` 项通过，其中 `17` 项针对新增 R8 验包边界。

最终正式 APK 为 `3,335,213` 字节，原非 R8 正式包为 `21,701,878` 字节，缩小约 `84.6%`。APK SHA-256 为 `c81924b0db367c26822c3032476eb1fbba59c02b49ff05b9e574e42886eb3789`；原正式证书 SHA-256 为 `ccfaf42f8f14bb36973aeb971572fcc956a256196f68ff088340dfa7eca96fe2`，v3 签名和 `16 KiB` 对齐通过。

签名后 R8 验包确认入口存在、公开且继承 API 102 模块类型，没有打入 compile-only API 定义，Xposed scope 与入口元数据一致，并通过 mapping 与真实 DEX 定义交叉确认实际改名。另检查了公开无参构造、三个回调签名、Manifest/alias、自定义 View 构造和枚举配置标识；`80` 项打包资源与原包逐字节一致。映射中记录的 R8 版本为 `8.13.19`。
