# 控制中心编辑器：第二步落地记录

日期：2026-09-30

## 本轮范围

仅升级编辑画布和卡片的 View 层。没有修改配置编码、草稿存储、推送校验、运行时布局应用、现有标准/紧凑布局，也没有构建发布 APK 或操作手机。

- `ControlCenterGridEditor` 保留逻辑网格、测量、坐标和既有长按拖放回调；删除可见网格、灰色渐变、常驻缩放箭头。
- `EditorItemHost` 是透明交互外壳，不承担材质或形状裁剪。按项目 ID 复用外壳和 Renderer；按 zIndex 排序。
- `ControlCenterCardView.Model` 是只读显示输入，不持有 Cell、配置仓库或编辑回调。卡片负责背景、轮廓、内容和裁剪。
- 矩形尊重独立圆角/全局圆角；胶囊使用短边的一半；圆形在非正方形占位内居中内接，不强制改写草稿宽高。
- 统一的半透明深色材质、开启白底、清晰内容、轻微阴影。滑块填充覆盖整个卡片宽度并受圆角裁剪；媒体播放图形和设备中心示意外观已更新。
- 新的纯内容路径复用 `ControlCenterPreviewTile` 图标，不叠加旧磁贴底板。
- 可编辑卡片不再使用整块截图缩略图；原截图保留在“真实布局参考”。不生成已烘焙背景随尺寸拉伸的伪实时预览。
- 缩放箭头暂时移除，宽高仍从点击后的原属性面板调整；Listener 的尺寸接口保留，供第三步选中态手势使用。

## 数据和状态约束

- 不自动替换用户布局为截图中的排列。
- 不强制把已有矩形改成圆形，也不将已有全局圆角强制迁移为 24dp。Renderer 独立使用时可以传入 20–24dp，实际编辑器尊重已保存数值。
- 显示状态目前是明确标注的示意：移动网络、蓝牙、旋转和静音等使用示例开启状态；亮度/音量为示例数值。不是实时系统状态。
- 隐藏项目继续低透明度显示，保留恢复入口；锁定项目仍可点击进入属性面板，但不能长按移动。
- 视图更新不会触发移动/尺寸回调或写配置。

## 尚未完成，不能作为完整 WYSIWYG 宣称

1. 没有接入真实壁纸取源和 backdrop blur。画布当前只叠加低透明度黑色遮罩，透出的是现有页面背景；半透明卡片是明确的降级材质。
2. 图标来自现有本地近似绘制，并非所有 OEM 原生图标的逐像素复刻。
3. 原生 SystemUI 运行时未替换 Renderer；特别是圆形在非正方形占位的策略，还需要后续与运行时共同对齐。
4. 第三步的长按 1.05 缩放、拖动抓取偏移修正、位移动画、选中态尺寸操作、删除/锁定/组合浮层尚未加入。
5. 没有真机的帧率、壁纸、SystemUI 应用效果验证。
