# FusionStatusBar v0.3.190

桌面应用选择弹窗新增搜索栏和应用图标，便于查找长列表中的应用。

## 更新内容

- 隐藏应用、启动应用、活动所属应用列表均支持按名称或包名即时搜索，忽略大小写与首尾空格。
- 搜索栏固定在列表上方，可一键清除；无结果时显示空状态，筛选不会改变弹窗高度。
- 应用行展示原彩色图标、名称、包名及冻结/停用/暂停状态。图标按需加载并使用有界缓存，缺失图标回退到系统默认图标。
- 隐藏应用使用复用列表行；跨搜索条件保留勾选，点击“完成”保存，取消则丢弃本次修改。
- 筛选后的选择按原始应用索引保存，保留既有目标和查询不到的隐藏应用配置。
- 弹窗沿用现有底部样式、主题颜色、动画和键盘尺寸调整逻辑。
