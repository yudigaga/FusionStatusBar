# FusionStatusBar v0.3.189

新增设置页的系统桌面重启入口，修复桌面应用选择器漏掉冻结应用的问题。

## 更新内容

- 设置页“模块维护”新增“重启系统桌面”，用于重启 `com.miui.home` 并返回桌面；原有“重启系统界面”继续单独提供。
- 重启确认使用项目现有的底部弹窗。确认后先等待设置保存完成；保存失败、页面销毁或重复请求不会执行重启。
- 桌面重启沿用项目的 root 执行方式，需要设备已授权 FusionStatusBar 使用 root。
- 应用查询包含已冻结/停用、停用桌面入口和已暂停的应用。活动选择包含已安装应用与停用的活动。
- 增加包可见性声明与停用组件匹配标志；选择器显示状态标记，不改变包或组件的启用状态。
- 冻结应用可以保留为配置目标；实际启动仍遵循系统的冻结限制。
