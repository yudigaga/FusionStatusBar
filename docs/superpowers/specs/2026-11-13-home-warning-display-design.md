# 手机管家首页提醒显示

用户希望隐藏首页“手机很危险，请立即修复”，并让病毒扫描、优化加速卡片采用普通文字颜色，不显示提醒红点与催促描述。

沿用手机管家独立配置机制，新增默认关闭的“隐藏首页风险提醒”。支持已核对的 `com.miui.securitycenter` 13.8.0（40001380）。开关与“锁定 666 分”独立，七种语言均有设置文案。

采用宿主首页视图绑定处的显示修改：原方法照常执行，之后处理目标文案、卡片颜色和红点；保留原生显示快照，关闭时恢复。实际扫描结果、风险模型、评分、扫描时间和扫描引擎继续由宿主维护。卡片使用中性说明，避免声称设备已经通过安全扫描。

对比方案：全局替换字符串无法覆盖颜色和红点；改扫描结果会影响实际检查。限定首页渲染的方式能完整覆盖用户指出的显示位置。

本次在现有脏工作区继续实现，保留此前修改；仅本地 Release 测试、lint、R8 构建和签名归档，不发布远程或安装手机。
