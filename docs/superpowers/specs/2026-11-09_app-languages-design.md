# 模块多语言与设置切换

用户确认支持跟随系统、简体中文、繁體中文、English、日本語、한국어、Русский、Español。使用项目现有 Miuix 设置选择器，放在“设置”的界面选项中；语言名称使用各语言自身名称。默认跟随系统，沿用中文默认资源以保留既有回退行为。

## 实现决策

- Android 最低33，采用 LocaleManager.applicationLocales；系统持久保存选择，空 LocaleList 表示跟随系统。声明 locale_config，供系统应用语言页识别。无需引入AppCompat或新依赖。
- 先将模块界面硬编码文字移到标准Android string/array资源，再完整补齐六种译文。资源覆盖导航、设置页、弹窗、编辑器、杂项与26项手机管家扩展说明。保留协议键、enum、spec、包名、日志、用户自定义文本和中文历法内容的原语义。
- 语言设置作用于模块界面。共享组件在宿主中使用时不能把模块R ID当作宿主资源ID读取；通过受限模块资源解析保留宿主语言配置，不修改宿主应用的语言设置。
- 语言改变会重建Activity；先等待当前设置写入完成，保留页签和编辑草稿，失败不切换。语言入口和所有选项允许长译文换行，沿用现有UI风格。
- 本次保留工作区全部既有改动，不创建丢失本地成果的分支，不提交或远端发布。

## 验收

每个语言资源键完整且格式占位符兼容；可选择七种语言与跟随系统，重启后保存；切换前后当前页面、已保存配置、控制中心草稿保留；未完成/失败写入不丢数据。默认中文旧测试、英文/俄文长文本与CJK设置界面检查；完整Debug/Release测试、lint、签名本地APK。未连接手机时明确不代表真实系统自动重建或ROM布局验收。
