# 启动协调器职责拆分（0.3.134）

`MainActivity` 在控制中心草稿恢复前需要遮住旧设置布局。配置读取和草稿恢复都是异步流程，Activity 还可能在就绪前收到文档选择器结果；这些顺序状态此前由 Activity 字段和回调内联维护。

本版本增加 `SettingsStartupCoordinator`，负责按“读取配置 → 恢复草稿 → 通知 Activity 就绪”的顺序推进，并在就绪后回放一个暂存的 Activity 结果。重复读取不会重复启动恢复；关闭后读取和恢复的迟到回调会被忽略。Activity 仍负责设置视图初始化、数据绑定和启动遮罩移除。

回归测试覆盖顺序、重复读取防重入、就绪通知只发生一次、延迟结果交接、Host 已销毁以及关闭后的迟到回调。原有冷启动页面测试继续验证主页面在初始化完成后进入概述页。

本次为本地代码和 Robolectric 验证；未进行实体手机安装、LSPosed 注入或 HyperOS 验收。
