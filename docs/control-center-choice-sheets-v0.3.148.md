# 控制中心选择面板与全局磁贴管理

日期：2026-10-02。版本：0.3.148 / 162。

## 界面统一

添加项目、配对两级选择、更多操作、组合成员选择和布局预设选择列表，统一使用现有设置页的圆角底部面板。共用面板尺寸、配色、字体和进出场动画；列表直接使用可回收的 ListView，不嵌套 ScrollView。图标保持 28dp，长名称可显示两行，顶部取消始终可操作。

选择后先关闭当前选择窗口，再执行一次原业务回调。取消不修改草稿；在组合属性中添加成员不会关闭父属性窗口。名称输入和危险操作确认保留原确认语义。

## 全局管理范围

“系统磁贴管理”改名为“全局磁贴开关”。它与画布当前布局的隐藏/移除不同，修改的是标准、紧凑布局共用的可用性设置。根据用户补充，管理范围扩展为已知系统磁贴、应用快捷磁贴、采集到的其他磁贴，以及旧配置中的磁贴。

全局管理目录不按 hidden 过滤；禁用项目和暂时不可发现的旧应用项目仍保留恢复入口。添加候选继续按 hidden 过滤。媒体、亮度等大型组件仍在画布中编辑，不作为 TileService 磁贴列出。

应用磁贴的完整类名和短类名按同一个服务处理，避免重复开关和绕过全局禁用。旧采集样式、缩略图和导入布局也兼容这两种写法，平台调用仍使用应用服务本身的准确组件名。

开关只修改编辑草稿，推送后应用；不删除两种布局中的项目，也不直接开关 Wi-Fi、蓝牙等实际功能。正式配置、布局和撤销/恢复行为通过回归验证。

## 验证与产物

修复前的真实活动 UI 回归确认添加对话框不是底部设置面板，“更多”仍为系统 PopupMenu。全局范围回归确认原界面缺少已发现应用、旧隐藏应用及采集磁贴的开关。

最终测试数量、Lint、APK 签名、版本一致性及 SHA-256 见 artifacts/releases/v0.3.148/release.json。实机截图及配置保留检查单独记录于 artifacts/validation/v0.3.148/。安装版本与 SystemUI 实际加载版本分别核对，不将应用界面验证当作新 Hook 注入验证。
