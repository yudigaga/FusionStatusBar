# FusionStatusBar 0.3.193

版本号 `0.3.193`，构建号 `207`。本次涵盖上一个远端正式版 `0.3.192` 到当前版本的全部变化。

## 更新内容

- 修复控制中心展开动画期间，自定义磁贴网格的外层高度被系统恢复为原生单行高度，导致编辑行位置异常的问题。等待动画稳定后重新校正高度，卸载网格时取消待执行的校正，并为重试设置时间上限。
- SystemUI 与小米桌面改为读取各自持久保存的配置快照。打开模块设置或保存已提交配置时，向两个宿主进程同步完整配置及动作桥接密钥。
- 正常运行的配置读取不再访问模块 Provider，运行时不需要靠设置应用常驻后台维持配置。
- 桌面手势直接向 SystemUI 发送经过认证的显式广播，移除每次手势对模块 Provider 队列的依赖。动作通过随机密钥、签名和一次性 nonce 校验；Android 14 及以上同时校验发送方身份。
- 配置广播要求发送方持有模块签名权限；配置快照和桥接密钥保存在宿主各自的设备保护存储中。
- 运行状态回报发给正在运行的设置接收器，未打开设置时不会为回报启动设置进程。宿主启动后的配置请求也仅能到达已注册的设置接收器。
- 快捷方式目录仅在设置页请求时刷新，控制中心预览仅在用户明确请求预览后读取，减少正常回桌面和控制中心运行时的跨包查询。

## 升级须知

1. 升级后先保持 FusionStatusBar 应用包和 LSPosed 模块启用。
2. 重启系统界面和小米桌面，以加载新版 Hook；再打开 FusionStatusBar 一次，初始化两个宿主进程的配置快照及桥接密钥。
3. 确认配置和手势生效后，可退出设置应用，或在包管理器中用 `pm disable` 停用设置应用包。LSPosed 模块本身仍须保持启用，修改配置前需重新启用应用包。
4. 保存配置时若某个宿主进程未运行，在该进程启动后再次打开设置完成同步。

包名、签名证书和四个作用域沿用 0.3.192，可覆盖安装。作用域为 `com.android.systemui`、`miui.systemui.plugin`、`com.miui.home` 和 `com.miui.securitycenter`。
