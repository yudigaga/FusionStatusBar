# 磁贴底板与外圈对齐 v0.3.162

本版修复 0.3.161 后反馈的小磁贴外圈偏高、底板底部被裁切问题，构建号 176。

## 原因与修改

自定义网格原先按整个格子绘制圆形外圈，并用同一个圆裁切原生 `QSTileItemView`。OEM 的真正底板位于内部 ImageView，保留 `icon_frame` 的顶部留白，尺寸也小于整个格子；因此填充圆和外圈既不同心，也不同径。

`ControlCenterRuntimeGrid` 现在将内部底板的实际边界转换到网格坐标，再放置描边和柔光。原生圆形磁贴取消父级格子圆形的二次裁切，由内部表面负责圆形裁切。按压缩放、位移会同步到装饰层，不使用固定像素补偿。点击区域仍保留完整格子范围，卡片、双按钮和其他形状继续使用各自原有布局。

## 验证

`ControlCenterTileAlignmentTest` 覆盖：

- 开启、关闭两种状态下，外圈对齐带顶部留白的实际底板。
- 底板向下移动时不会被外层圆形削掉底部。
- 内部视图平移、缩放时，外圈无需再次网格布局即可跟随。
- 整个控制中心缩放、平移时，不重复应用面板变换。

前三个用例均在修复前执行失败，修复后通过。原生布局材质边界、网格形状和材质刷新回归同步检查。

发布执行 `tools/release.ps1`，准确测试数量、lint、签名及 APK 哈希见 `artifacts/releases/v0.3.162/release.json`。本次为本地构建验证，未安装手机或执行 HyperOS 实机画面验收。
