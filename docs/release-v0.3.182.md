# FusionStatusBar v0.3.182

本版包含控制中心编辑与运行时更新、诊断导出及系统菜单滑条修正。

## 更新内容

- 控制中心布局与外观设置迁入独立页面编辑会话，支持按画布隔离草稿、撤销/重做、属性编辑和手势提交。
- 增加 OEM 宿主适配边界，集中处理面板内容映射、宿主快照恢复及磁贴和组件容器绑定。
- 材质会话统一负责组件/卡片背景、裁剪轮廓、原生 Drawable 回调的应用与恢复；网格与配置刷新按实际变化执行，避免重复全量同步。
- 按宿主 ClassLoader 记录插件能力和失败原因；配置变更只刷新受影响功能。
- 新增诊断快照与日志范围控制，支持脱敏、容量/时长限制、截断标记和取消清理。
- 反射查找增加线程局部命中快路径，同时保留按实际 Class 隔离的缓存，避免插件重载间串用。
- 遥测仅在存在消费者且屏幕交互时轮询；熄屏暂停，亮屏恢复。
- 5G 磁贴预览展示真实标签和开启状态；组合卡片按成员槽位缩放预览，避免裁切 OEM 固定尺寸内容。
- 控制中心和音量菜单滑条按完整轨道轮廓与进度区域相交裁剪填充，保留原生分界线和动态轮廓更新。
- 音量菜单填充贴合描边内缘，不再额外缩进 1 dp；使用浮点描边宽度，避免非整数密度下出现间隙。

## 安装与兼容性

- 包名：`io.github.yudigaga.fusionstatusbar`；最低 Android API 33，需要支持 LibXposed API 102 的框架。
- 作用域为 `com.android.systemui`；设备存在 `miui.systemui.plugin` 时也勾选。
- 本版未进行实体设备安装、SystemUI 注入、目标 ROM 视觉或性能验收。测试通过不代表特定 HyperOS/GPU 已完成兼容验证。
