# 设置页内选择器统一（0.3.141）

状态栏监测与状态栏布局设置原来使用 Android `Spinner` 的系统下拉窗口。设置页本身已经是带独立进出场动画的底部面板，两个窗口各自切换会让选择过程显得割裂。这个原因目前是基于窗口结构的判断，尚无目标手机帧耗时数据佐证。

本版将这些选择控件改为设置面板内展开的选项列表。打开选项不会再创建 `Spinner` 下拉窗口或第二个 `Dialog`；选择后原有配置回调只在值变化时调用一次，当前值、选中标记、触控高度和选择项无障碍状态均保留。展开时会将选项组滚入面板视口，窄屏仍由原 `ScrollView` 承载。

Robolectric 回归覆盖系统 Spinner 移除、同一窗口内展开、打开不写配置、更改值回调一次、重选当前值不写回、宿主取消以及双排布局关闭时选择器禁用。响应式回归在浅色和深色主题下使用 320 dp 窄屏、1.5 倍字体，检查展开列表可见、内容不裁切及触控高度。

本次本地测试能证明控件结构、选择语义和大字布局，但不能测量设备上的动画帧时间。因此不以该改动宣称设置弹窗卡顿已解决；仍需在目标手机对选择与设置页开合各采样后判定效果。
