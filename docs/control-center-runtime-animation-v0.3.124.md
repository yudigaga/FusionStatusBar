# 运行时磁贴光环与面板动画

日期：2026-10-01。版本：0.3.124 / 138。

## 输入与证据边界

用户报告：推送后圆形磁贴外围出现重影；展开与收起时主要只有原生编辑按钮移动，自定义布局停顿后整体消失。截图显示原生圆形表面外围还有较大的半透明底板。

复查 `../LSPosed_20260930_234838.zip`。最新模块加载记录仍为 0.3.122，23:46-23:47 的运行时记录为 `plan=empty`，不能当作本次推送后的完整动画轨迹。

该包也保留历史挂载记录：成员 `log/modules_2026-09-30T14:20:21.582119.log` 的 13884-13887 行，23:22:17，18 个绑定、36 个子视图，presentation 记录显示外层 alpha/scale/translation 被归一且 `changed=true`。这些记录支持当前实现的结构分析，但不是这张新截图的逐帧证据。main 缓冲区从 23:48:11 开始，无法用它证明更早收起动画的耗时。

## 可复现原因

1. GridView 为每个原生项目再添加一块配置底板。小磁贴自身带内边距并绘制圆形背景，额外底板覆盖整个格位，形成第二圈更大的半透明光环。
2. GridState 对原生 RecyclerView 中的外层宿主也应用 HolderPresentation.freeze，使其忽略 alpha、scale、translation。内嵌组件没有独立分发的面板展开参数，需要局部固定，但外层宿主是应该接收原生展开/收起帧的对象。
3. 160ms 延迟归一回调会重写外层可见性和变换，可能在收起途中把宿主重新显露。
4. enforceOuterHeight 在尺寸不变时仍 requestLayout，并从布局监听器再次执行，造成无必要的重复布局请求。这是确定的冗余行为，不代表已测得用户停顿全部由它导致。

## 修改

- 原生圆形磁贴、原生大卡片和原生组件使用自身状态背景，不再叠加整格底板；组合项目和需要形状补底的项目保留原有处理。
- 不再冻结外层宿主，不再在 attach/settled 阶段重置其透明度、可见性、缩放或位移。
- 嵌套 holder 的局部固定与卸载恢复保留，整组布局通过原生外层宿主接收面板动画，避免父子重复应用同一动作。
- unbind 仅恢复本模块实际修改的层级、背景、尺寸、交互属性，不回放过时的动画属性快照。
- 尺寸未变时不追加 requestLayout；尺寸与 minimumHeight 确需修正时仍依赖原生 setter 请求布局。
- 现有挂载/归一日志新增 `carrierAnimation=native`，不记录逐帧日志。

不改变草稿、布局序列化、推送协议、采集格式或磁贴真实状态。

## 本地验证

修复前执行定向测试，四项均失败：原生圆形外围像素多出半透明光环、宿主不能跟随动画帧、延迟任务重置收起状态、尺寸不变仍请求布局。修改后通过。

动画测试构造模拟 OEM holder，但调用真实 GridState 的 mount、attach、归一、unbind 路径，覆盖嵌套 holder 固定与恢复、父宿主动画保持、层级及尺寸还原。像素测试使用 Robolectric 原生图形后端，验证原生圆形表面以外不再绘制额外光环。原有矩形、胶囊、圆形和组合裁剪测试保留。

最终执行 `:app:testDebugUnitTest :app:lintDebug :app:assembleDebug` 成功；241 项测试全部通过，无失败、错误或跳过。Lint 为 0 errors、57 warnings。apksigner 验证通过，aapt 与打包的 module.prop 均确认 0.3.124 / 138。

这是本地回归，不是真机动画、帧率或消失时延验证。整组跟随宿主不等于恢复每张原生卡片各自的错峰动画；其他 OEM 动画实现仍需设备观察。
