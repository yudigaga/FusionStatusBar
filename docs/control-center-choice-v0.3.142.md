# 控制中心编辑器选择器统一（0.3.142）

控制中心项目编辑面板中的卡片样式、组合卡片排列/背景和磁贴形状原来仍使用 Android `Spinner` 下拉。它们与底部编辑面板的动画分属不同窗口，选择时会产生与设置页相同的割裂感。

本版将这些控件改为面板内展开的 `SettingsChoiceSelector`。卡片样式继续把“自定义”作为仅展示、不可点击的选项；项目锁定时整个选择器收起并禁用。组合卡片的两个枚举选择继续通过当前项目提交和刷新，磁贴形状继续按原五项索引映射宽高并写入编辑草稿。选择当前值不会新增草稿或撤销记录，变化仍沿用原有编辑会话。

本地回归覆盖卡片样式草稿/撤销、锁定与自定义禁用、浅色/深色渲染、组合排列和背景选择，以及无 Spinner 的内嵌交互。该改动只证明窗口结构和编辑语义，不能替代目标手机帧耗时采样。
