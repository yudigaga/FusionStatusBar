# 空白组合卡与内部属性

日期：2026-10-01。版本：0.3.125 / 139。

## 功能范围

按用户最终确认的方案，不新增模板页面，不替换现有布局。在“添加项目”中保留原双磁贴组合入口并新增“空白组合卡”。创建后进入既有单项目属性面板。

- 空容器有独立稳定 ID、位置、宽高、形状、圆角、锁定、隐藏和层级；没有成员也可保存与渲染。
- 最多七个已有磁贴。可添加未使用的磁贴，也可将当前画布上的未锁定单独磁贴移入；不可从锁定项目或其他组合中直接抢占成员。
- 内部排列包括纵向列表、横向排列、均匀网格、大小混排、自由排列。大小混排为三大四小，纵向列表可组成参考图的三项联网卡。
- 每个成员可排序、移除、编辑内部 XY、宽高与名称/状态显示。内部采用 12x12 相对坐标，越界、重叠和重复成员拒绝提交；自由排列添加成员时保留已有坐标，寻找空位。
- 容器背景提供深色、半透明雾面和透明，描边独立开关，形状/圆角继续使用现有属性。材质在编辑器与运行时共用，并非只在预览生效。
- 整体拖动、缩放、锁定、隐藏、移除与拆分继续沿用原草稿事务。成员移入和拆分可以撤销；不自动保存配置，仍需显式推送。

媒体、亮度和音量保持独立原生组件。本版没有把它们嵌入组合，也没有新增横向媒体重排或整套模板。半透明雾面是统一的静态材质，不是新增系统级实时毛玻璃。

## 数据与运行时

`ControlCenterLayoutPlan` 从版本 4 升到 5，仅 GROUP 项追加有界成员载荷。保留对 1 至 4 版读取；所有现有 Item 变换保留 group 数据。新版本布局不能供旧模块读取，因此覆盖安装后必须重启 SystemUI 再推送。

`ControlCenterGroupData` 管理成员、内部坐标、排列、背景与描边。`ControlCenterGroupView` 为编辑器和运行时提供同一套布局与裁剪；整体只有一层容器底板。

运行时经原有 QSRecord/holder 工厂创建原生磁贴，`ControlCenterGroupEntry` 缩放已绑定的原生视图，不替换为图片或模拟开关。点击与长按转发到原生磁贴，名称/状态从原生状态读取，更新检查限频。保留 0.3.124 的外层宿主动画，不把组合容器额外冻结。内层局部变换受约束，卸载时恢复标志、解绑与回收。

成员不再可用时在运行时过滤，但容器和其余成员位置保留。旧的单磁贴宽高设置不应意外改变整个组合容器大小。

采集本模块运行时网格时，参考缓存附带确切 editablePlan 与间距，组合成员状态单独采样。重新导入可保留组合结构与内部排列，避免把三项/七项卡片摊平到外部网格。普通原生布局仍走既有几何推断导入。
