# Hook 安装重试协调（0.3.140）

本版本增加 `BoundedHookRetry`，统一调度 fixed-delay Hook 安装重试：同一策略最多只有一个待执行任务，完成条件满足后停止，达到预算上限后不再排队，主线程调度器拒绝或抛错时释放 pending 状态和本次预算消耗。

SystemUI 全局 Hook 安装与控制中心插件 Hook 仍是两个独立策略实例，分别保留原有触发条件、4 次/8 次预算和 3 秒间隔。插件重试仍遍历存活的已跟踪 ClassLoader；全局重试仍依据真实 Hook 句柄表中的失败状态。

单测覆盖固定延迟、最多一个待处理重试、条件满足时停止、不同策略预算隔离，以及调度拒绝后的再次排队。没有进行设备验证。
