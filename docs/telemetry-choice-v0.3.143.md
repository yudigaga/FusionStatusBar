# 遥测位置选择器统一（0.3.143）

主设置页的“状态栏监测”包含温度、功率和电流/网速三组位置设置。此前这些位置仍使用 Android `Spinner`，点击后会创建独立下拉窗口，与设置页的展开动画和窗口层级不一致。

本版将三个位置控件改为面板内展开的 `SettingsChoiceSelector`。选择器继续使用原有四个位置标签和配置索引；遥测项关闭时整体禁用并收起，配置刷新时同步当前值，重新选择当前值不触发写回。有效位置变化仍通过 `MainActivity.update()` 进入原有保存和预览刷新流程。

新增 Robolectric 回归检查三个位置控件不含 `Spinner`，启用对应遥测项后可在当前设置窗口内展开选项并更新配置。完整本地测试共 586 项，失败/错误/跳过均为 0；lint 0 错误、60 警告。该验证覆盖窗口结构和配置语义，不能替代目标设备上的帧耗时或实体机验收。
