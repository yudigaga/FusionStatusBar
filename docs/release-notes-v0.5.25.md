# FusionStatusBar 0.5.25

版本 `0.5.25`，Android 构建号 `239`，沿用正式证书和 R8 压缩、优化与混淆。本版主要增加应用多语言及切换前的保存保护。

## 功能更新

- 新增“设置 → 界面 → 应用语言”，支持跟随系统，以及简体中文、繁體中文、English、日本語、한국어、Русский、Español。七种语言各包含 850 条界面字符串，覆盖设置、导航、对话框、控制中心编辑器、无障碍提示及手机管家扩展设置。
- 切换前等待普通设置保存或已明确发起的控制中心发布完成；失败时取消切换。旋转后恢复待完成事务，保留页面、滚动、编辑草稿及杂项状态。未推送草稿不会因切换语言自动发布。
- 使用 Android 原生 `LocaleManager` 保存模块应用语言；跟随系统时清空覆盖。用户自定义文本、宿主名称、配置键、时钟格式与既有中文农历语义保持原值。俄文长导航支持换行和字号适配。
- 标准构建、归档和 CI 统一为 Release 流程，校验实际 DEX 的 R8 标记、版本和映射 ID。发布集成保留上一版独立验包工具及入口、继承、API 打包边界和实际改名门槛。

语言切换作用于模块设置应用；本版未新增 LSPosed 作用域。原有充电图标、截图剪贴板及手机管家扩展沿用 [0.5.24 的作用域、加载方式与硬件限制](release-notes-v0.5.24.md)。应用语言功能和验证细节见[多语言实施记录](2026-11-09_app-languages.md)。
