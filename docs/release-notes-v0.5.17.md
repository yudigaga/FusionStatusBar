# FusionStatusBar 0.5.17

本地 Release APK，版本 `0.5.17` / Android 构建号 `231`，使用原有正式证书签名，支持从 `0.5.16` 覆盖升级。

## 更新内容

- 桌面手势增加“返回停顿”：有效侧边返回滑动停稳约 0.5 秒后松手，执行所选动作；普通返回保持原路径。
- 侧滑返回外观增加系统默认、经典水滴、灵动胶囊、柔和涟漪、霓虹光环五个选项，普通返回和返回停顿共用所选外观。
- 支持背景色、箭头色、透明度、色板及 RGB/ARGB 输入，并提供动画示意预览；选择系统默认可恢复原生绘制。
- 由系统桌面识别侧边输入，复用 SystemUI 签名动作通道；先取消原生返回并完成宿主收尾，再执行自定义动作。原生动画反馈继续执行。

安装后重启系统桌面和系统界面，或重启设备；确认 LSPosed 的 `com.miui.home` 与 `com.android.systemui` 作用域已启用。
