# FusionStatusBar 0.3.198

版本号 `0.3.198`，构建号 `212`。基于 0.3.197 优化融合图标，原有设置界面、预览布局及切换方式保持不变。

## 图标调整

- 电量弧线使用更饱满的圆角笔画，优化数字、Wi-Fi、闪电和信号圆点的比例与间距。
- 充电使用绿色电量弧线和单色闪电；快充使用金色闪电；省电使用黄色弧线；危险电量使用红色弧线。文字、Wi-Fi 和蜂窝信号继续跟随状态栏颜色，适配浅色与深色背景。
- 保留 Wi-Fi 独立强度、双卡信号、各部分的位置交换、独立缩放以及顶部信号翻转。按用户已有位置设置显示，不重置布局或增加新的预览卡片。
- 最大粗细下为弧线、闪电和信号圆点留出间隙；初始字体粗细与默认配置保持一致。
- 接入系统省电状态与变化广播。快充依据系统提供的最大充电电流、电压能力字段按 AOSP 经典阈值分类；字段缺失时使用普通充电样式，拔电或普通充电更新会清除快充状态。这不代表测量瞬时功率或确认厂商私有快充协议。

## 安装与验证范围

使用原正式证书签名，可覆盖更新 0.3.197。更新后重启系统界面或设备，再打开设置同步配置。从更早版本升级时，仍按 [0.3.197 升级说明](release-notes-v0.3.197.md) 核对 System 作用域。

- 本次本地 Debug、Release 各通过 **46 项相关测试**，覆盖图标几何、内容位置与缩放、Wi-Fi/双卡状态、六状态图像及电池状态更新；并非本地完整测试集。
- 工具回归测试 28 项通过。两套 lint 均为 0 错误、99 条警告，高风险策略通过。
- Manifest、BuildConfig、Xposed 版本及作用域一致；正式 APK 为非调试构建，签名验证和 16 KiB ZIP 对齐检查通过。
- 本版尚未进行设备安装、Hook 注入、目标 ROM 功能或实机性能验收。远端完整 CI 的结果以对应发布提交的 GitHub Actions 为准。
