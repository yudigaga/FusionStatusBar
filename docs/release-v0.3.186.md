# FusionStatusBar v0.3.186

本版调整 Wi-Fi 强度图标的弧线间距，并记录蜂窝信号与预览值的差异。

## 更新内容

- Wi-Fi 图标使用两层弧线和信号点表示五级 Wi-Fi 强度；减细弧线，避免状态栏小尺寸下相邻弧线和信号点粘连。
- 蜂窝双排信号继续使用 Telephony 的 SIM 信号级别。随附日志在 02:55 附近记录到注册蜂窝信号 `level=1`；设置页预览使用固定的 4/3 示例值，不能代表设备此刻的实测信号。
- 连接 Wi-Fi 时，Wi-Fi 图标显示 Wi-Fi 强度，双排点阵显示移动信号；二者不共用强度数据。

## 构建验证

- Debug 与 Release 各 1005 项单元测试通过，0 失败、0 错误、0 跳过。
- 两套 lint 结果、正式 APK 摘要、签名证书、ZIP 对齐和源码快照见同目录 `release.json` 与 `validation.md`。
- 本次基于包含未提交修复的工作区构建；发布清单保留源码快照并标记 `sourceDirty=true`。

## 实机状态

本次没有连接 Android 设备。新版弧线观感尚未在设备上复核；日志所示蜂窝 level 1 说明“单格”与当时 Telephony 上报一致，若与系统原生信号格数不符，还需进一步对比该 ROM 的信号等级映射。
