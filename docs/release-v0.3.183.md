# FusionStatusBar v0.3.183

本版针对控制中心缩放和动画、融合图标排布，以及应用桌面入口提供修复。

## 更新内容

- 控制中心内容缩放统一作用于磁贴、组件外框、内部图形、间距和占用高度；缩放视口保持放大内容可横向访问。
- 5G 圆形磁贴对齐原生磁贴缩进后的可见圆面。
- 隐藏控制中心日期或运营商时保留原有布局空间，避免融合图标和系统图标下移。
- 移除收起动画期间可能重置面板显示状态的延迟工作；仅在自定义控制中心启用时缩短原生展开和模糊弹簧的收尾，并保留原生动画监听器。
- 融合图标的电量百分比、Wi-Fi/5G 与双排信号可交换顶部、中间和底部位置，并能分别调节尺寸。双排信号移到顶部时自动翻转；整体大小仍将外环和全部内容一起等比缩放。
- 概述页新增隐藏桌面应用图标开关。关闭桌面入口后，LSPosed 设置入口仍可打开。
- 配置 schema 更新至 6。旧配置保留默认排布；配置导入与导出继续验证 schema 和字段完整性。
