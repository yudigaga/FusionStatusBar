# 通知中心 Hook 安装职责拆分（0.3.137）

本版本增加 `NotificationHookInstaller`，负责在指定 SystemUI ClassLoader 中解析并注册通知中心相关 Hook：通知头部六个声明方法、展开控制器时间尺寸、展开回调、通知列表顶部间距和布局，以及原生网速可见性。

安装器不持有配置、时钟控制器或列表状态。它只通过类解析、成员解析、Hook 注册和回调映射接口工作，并回传通知展开字段、通知列表字段链和顶部间距方法。`SystemUiHooks` 继续负责这些字段的运行时使用、应用回执和全局重试。

测试覆盖目标缺失、错误重载、字段链回传、重复注册和失败重试。通知列表的两个方法独立安装，字段缺失不会伪装成 Hook 成功。本次没有进行设备验证。
