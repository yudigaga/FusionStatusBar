# FusionStatusBar v0.3.192

完成剩余页面的 Miuix 控件迁移，保留现有配置、Hook 和控制中心编辑引擎。

本次公开发布相对远端 0.3.187 的完整变化见 [0.3.188 到 0.3.192 汇总](release-notes-v0.3.192.md)。

## 更新内容

- 状态栏、通知栏、控制中心与设置页的设置行、开关、滑块、输入框、分组标题和命令按钮使用 Miuix。
- 五个页面统一使用 Miuix NavigationBar；状态栏预览模式与启动加载界面同步迁移。
- 公共设置、选择列表、属性、组合成员、恢复确认、备份确认、预设输入和诊断选项使用 WindowBottomSheet。
- 控制中心画布、原生布局参考、状态栏和通知预览继续复用原有绘制与触摸逻辑；Java 回调通过控件绑定层连接 Compose 可见控件。
- 保留控制中心草稿、撤销/重做、锁定、组合、样式、布局校验与明确推送的行为，状态栏和通知栏仍使用原有配置保存协议。
- 选择列表保留图标、可用状态和原始条目 ID；深色主题为独立控件宿主提供内容色，时间格式与预设输入继续显示校验错误。
- 导航高度按字体与标签测量，组合成员的图标尺寸输入与滑杆保持双向同步，命令按钮保留主按钮和选中状态。
- 后台读写任务和所有 Compose 窗口在 Activity 销毁时释放；系统文件选择器继续处理导入导出。

- 既有控制中心流程测试同步适配 Compose 窗口，保留图标来源、组合、尺寸、样式、锁定和恢复的回归检查。
