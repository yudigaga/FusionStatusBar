# 卡片外观与参考图对齐

版本：0.3.121 / 135。

## 范围

以用户提供的 HyperOS 控制中心截图为视觉参考，不覆盖既有布局，不读取系统壁纸，继续使用 v0.3.120 的内置黑色预模糊背景。

单项目属性中的“卡片样式”提供七个选项：跟随默认、微圆角 8dp、经典圆角 20dp、柔和圆角 28dp、大圆角 40dp、胶囊、圆形。手动圆角保留 0 至 64dp，0 跟随全局；非预设值显示“自定义”。圆形与胶囊自动计算圆角。样式仅映射到既有 Shape 和 cornerRadius 字段，不引入新的存储格式，也不改变宽高、位置、组合关系、隐藏或层级。

设置入口位于单项目属性面板。切换产生一次可撤销的草稿修改，锁定时不可操作，不直接保存或推送；标准与紧凑布局各自独立。解除锁定会同步恢复可操作状态。

## 渲染

- 图文卡片改为固定图标区与独立文字区，小尺寸自动缩小文字并省略超长内容。
- 圆形磁贴只显示图标，白色开启底与深色半透明关闭底保留。
- 修正图文横卡判定：宽度格数大于高度格数，且非圆形，与运行时 usesCardView 的规则一致；不再把 2x2 方形磁贴误画成横卡。
- 使用 Google Material Icons 的本地矢量资源代替手绘简化图标；移动数据为绿色上下箭头、静音为红色铃铛、截图和录屏使用不同图标。
- 媒体卡片补齐投屏图标和播放控制，竖向滑块保留亮度约 70%、音量约 20% 的示意填充，设备中心文字适应窄尺寸。
- 绘制阶段复用 Drawable/Paint，避免原图标实现中每帧创建 Path/Paint；未进行真机帧率性能对比。

Material Icons 使用 Apache-2.0，许可证在 `third_party/material-icons/` 和 APK 的 `assets/licenses/material-icons.txt` 中。转换脚本 `tools/import_control_center_icons.py` 仅供开发使用，构建和运行无需联网。

测试覆盖七种预设的旧格式往返、组合信息保留、默认/自定义识别、草稿撤销、不自动保存、独立布局、锁定、手动圆角同步、横卡判定、图标像素非空、窄尺寸文本和明暗选择器。

最终执行 `:app:testDebugUnitTest :app:lintDebug :app:assembleDebug` 成功；219 项测试全部通过，失败、错误和跳过均为 0。Lint 为 0 errors、56 warnings（含新增代码构建视图的 ViewConstructor 工具构造器提示）。APK 元数据与 module.prop 均为 0.3.121 / 135，21 个图标资源及许可证已核对入包。

Robolectric 原生渲染截图位于 `app/build/reports/control-center-styles/`：360px 和 440px 的参考组合、七种外观、320px 明暗样式选择器。参考组合只存在于测试中，未注入用户草稿。

截图无法反推出真实背景透明度、模糊半径或设备 dp；此次没有宣称像素级复刻。预览状态与图标不是实时 SystemUI 状态或小米原始图标；SystemUI 继续使用原生组件。形状预设沿用已有运行时支持，尚未在用户手机复测。透明度、描边、逐卡片材质皮肤不在本次范围。
