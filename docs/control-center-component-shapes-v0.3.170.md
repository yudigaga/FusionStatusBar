# 组件形状与底色统一 v0.3.170

用户反馈 0.3.169 仅在胶囊形状下看见音乐、融合中心与未开启磁贴的底色一致，并询问是否仍存在遮罩。最新 `LSPosed_20261005_011921.zip` 确认运行 0.3.169 (183)，SOFT_GLASS、blur=100/100/100，组件 Hook 和布局重建成功。旧日志没有组件的背景和形状细节，不能直接证明其具体遮罩来源，也不能视为已排除渲染层问题。

代码中的组件路径只给外层设定裁剪，对原生背景改色后仍绘制其旧形状。与磁贴的独立底板接管相比，组件存在两套轮廓，且之前仅比较颜色中心的测试没有覆盖它。网格像素回归在旧代码下失败：系统圆角与选定圆角不同时，配置形状内部出现缺色区域；系统替换或重新染色底板也可重新改变可见填色。这些结果确认代码缺口，不能替代对用户实机画面的直接复现。

本版让音乐和融合中心在自定义材质下复用单底板绘制路径，同时处理选定形状、未开启状态色和卡片透明度。原生底板保留但不叠加绘制；重建背景时重新接管，退出自定义或进入原生编辑时恢复。组件的外层轮廓同步保持 alpha=0，不新增置顶遮挡层。形状、颜色不变时不重复发起 Drawable 重绘。

测试覆盖音乐 2×2、融合中心 4×1 的所有预设以及自定义半径，比较中心和边角像素；覆盖背景替换/重染以及禁用后的背景、轮廓恢复。此前组件材质接管、内部控件保色、原生编辑、透明度测试继续运行。

诊断增加 `component surface layers`，记录 spec、形状、半径、实际背景、View alpha、outline alpha，以及组件根部的软件接管与原生背景模糊状态。每次绑定只记录一次，不读取文本内容。

全量测试、lint、APK 签名和版本一致性结果见 `artifacts/releases/v0.3.170/release.json`。未安装或操作实体手机，最终颜色和轮廓效果仍需用户实机确认。
