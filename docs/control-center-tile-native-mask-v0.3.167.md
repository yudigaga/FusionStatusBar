# 磁贴原生背景层接管 v0.3.167

用户补充确认：大圆角和胶囊并非正常，只是内层遮罩铺满较大的底板后不易察觉；圆形、其他预设也有同类问题。

最新的 `LSPosed_20261004_213527.zip` 确认设备运行 0.3.166。`custom_5g` 的外部矩形槽位为 275×313，内部图标 ImageView 为 249×249，内层图像仅为居中的 124×124 VectorDrawable。内部 `TileSurfaceDrawable` 在外部底板模式不绘制填色，因此截图中的 249px 白色内层不能由它生成。日志没有记录实际硬件模糊模式，故不能仅凭日志断定最终绘制者。

代码检查发现一个明确冲突：软件底板接管图标时，原生视图模糊模式被置零，但 `updateNativeSurface()` 随后仍将同一 ImageView 的背景模糊模式设为 1、半径设为非零。这允许原生背景层继续覆盖软件底板。现在软件接管期间同时关闭原生视图模糊、背景模糊半径/模式与混色；系统后续重设这些属性时继续拦截。退出自定义时恢复系统最后请求的值。原生材质仍由系统绘制的组件不受此分支影响。

Robolectric 回归覆盖圆形、矩形、胶囊，首次接管、系统晚到更新和关闭/编辑模式恢复。0.3.167 的图层日志还会记录 ImageView 实际读取到的背景模糊模式/半径，便于实机核对。测试只能证明代码状态和模拟路径；白色内层是否在目标 ROM 上消失需要安装后截图确认。如果仍存在，应继续排查 AnimatedVectorDrawable 内层或未暴露的 RenderNode 效果。
