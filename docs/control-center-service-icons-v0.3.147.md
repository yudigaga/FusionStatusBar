# 设备验证发现的应用磁贴白块

日期：2026-10-02。版本：0.3.147 / 161。

安装 0.3.146 到连接的 Xiaomi M2105K81AC（Android 16 / API 36）后，实际画布中的小米互传、屏幕录制、投屏仍显示白块。安装包 SHA-256 与 0.3.146 归档一致，因此并非旧安装包。

## 实际证据

只读 app_process 探针调用归档 APK 的同一 `ControlCenterAppTiles.query`，读取到三项内容完全相同的主题白板；直接通过 `getResourcesForApplication` 加载各服务声明的图标资源后，分别得到互传、录屏和投屏图案。证据位于 `artifacts/validation/v0.3.146/20261002-icon-ui/` 的 `canvas-before.png`、`service-icons/`、`raw-service-icons/`。探针不在交付 APK 内。

## 修复

- 图标加载先读取服务声明资源，损坏或缺失时读取应用声明资源，再使用平台加载器兜底。避免 OEM 启动器主题占位图覆盖服务图标。
- 主题白板边缘有阴影，原来的全图色阶检查误判它包含内容。现在结合近不透明内部区域判定无细节中性底板；有效彩色、灰阶 logo 和真实图标均保留。
- 仅真正单色的图形随背景调整前景色；多灰阶应用图不会整体着色而丢失细节。

回归先复现了真实主题白板、多灰阶 logo 被抹除，以及两个声明资源加载/回退错误。最终全量测试、Lint、签名与版本校验以 `artifacts/releases/v0.3.147/release.json` 为准。设备验证记录与此构建记录分开保存；不将安装成功等同于 SystemUI Hook 已加载新版。
