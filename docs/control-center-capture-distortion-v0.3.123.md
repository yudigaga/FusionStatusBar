## 修正

旧采样把整个 Drawable 边界改为 64x64，却不会同步缩小固定尺寸的子图层，导致图标边缘裁切甚至完全不可见。新版识别已知固定尺寸前景层，保留原始 Drawable 与子图层边界，仅通过 Canvas 等比变换生成 128x128 透明图标。不会把背景层一起当图标带入。

旧导入用多数小磁贴的外框宽度作为列单元，外框已包含间距时会得出零间距。新采集使用小磁贴的可见表面边界；兼容旧记录时优先采用竖向单列滑块的宽度作为可靠单元尺寸。间距仍由采集几何与 density 换算，不写死。

采集 JSON 增加 `iconSampling=2`。旧版本生成的图标位图不再作为原生图标展示，但保留其文字、状态和布局数据；重新拉取可获得修正后的图标。未知复杂图层保持本地备用图标，不假定任意最后一层都是图标。

增加低频导入日志，记录列数、间距 dp、项目数，不记录网络名或磁贴文字。草稿、推送协议、拖动、撤销及运行时布局行为未改动。
